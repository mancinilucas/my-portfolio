## Portfólio — Lucas Mancini

Este repositório contém a versão v1 do portfólio/landing page profissional de Lucas Mancini. A finalidade é apresentar serviços, projetos e formas de contato em uma única página responsiva construída com foco em performance e acessibilidade.

### Tecnologias

- Vite (build/dev)
- React + TypeScript
- Tailwind CSS (estilização)
- shadcn-ui (componentes)
- Framer Motion (animações)

### Requisitos

- Node.js (recomendado 18+)
- pnpm (recomendado) — alternativamente npm/yarn

### Como clonar e rodar localmente

```bash
# clonar o repositório
git clone <YOUR_GIT_URL>
cd <YOUR_PROJECT_NAME>

# instalar dependências (com pnpm)
pnpm install

# rodar em modo desenvolvimento
pnpm run dev

# build para produção
pnpm run build

# rodar preview do build
pnpm run preview
```

### Scripts úteis

- `pnpm run dev` — inicia servidor de desenvolvimento (Vite)
- `pnpm run build` — gera build de produção
- `pnpm run preview` — serve o build localmente
- `pnpm run lint` — executa ESLint
- `pnpm run format` — formata o código com Prettier
